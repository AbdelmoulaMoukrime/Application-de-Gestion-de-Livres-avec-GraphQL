2. Exécuter l'application \
a) Lancez l'application Spring Boot \
b) Accédez à l'application : http://localhost:8080 \
c) Testez l'API GraphQL : http://localhost:8080/graphql-ui \
d) Ajoutez de nouveaux livres via le formulaire \
e) Recherchez des livres par titre \
f) Filtrez par catégorie \
g) Testez des requêtes GraphQL directement dans la console \
h) Modifiez le prix d'un livre existant\
